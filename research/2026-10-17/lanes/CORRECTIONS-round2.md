# Round-2 model corrections (critic item A10)

Date: 2026-10-17. Package: `r2-model-corrections`. Paid Azure spend: INR 0. Nothing was committed.

**What this did.** The round-1 verifiers' corrections were applied to the model files themselves, so the files now show
the corrected numbers. Before this, the corrections existed only in `verify.md` and in SYNTHESIS prose.

**Method, the same for every lane:**
1. Re-run the round-1 script in a scratch copy and confirm it reproduces the lane's outputs. Byte for byte for l2, l5,
   l6 and l7. For l8, every round-1 INR value is re-derived exactly at ₹88 before being rewritten.
2. Copy every file about to change to `<name>.round1.<ext>`.
3. Edit the original and regenerate.
4. Diff the results: only the intended columns or values may change.

The l2 workbook was also recalculated in LibreOffice. Every scenario column equals the Python value (max |diff| 4e-15).

## 7. l3-segments: scorecard variants

The frozen weights and sub-scores are reused unchanged.
- **V1** sets `post_sales_share` to 0 and renormalises over 90.
- **V2** applies one symmetric outcome gate to every segment with a value-gate row:
  - test: one outcome's low-end value must cover VP's managed COGS for one call;
  - COGS is the round-2 l2 MC p50 for A, ₹5.88/min, at 2.0 min per call (D2C 0.94 min);
  - D2C's value is already per COD order called.
- **V3** is V1 and V2 together.

**Resulting ranks:**
- **V1 (`post_sales_share` = 0):**
  - insurance renewals and real estate tie for #1 at 3.722, and the Dirichlet top-1 split is a coin flip (0.46 vs 0.48);
  - edtech admissions rises to #3;
  - fintech onboarding is #4, with D2C and solar tied at #5;
  - lending collections falls from #4 to #8.
- **V2 (symmetric gate):**
  - every gated segment passes, so the ranks equal the frozen scorecard and D2C stays #3;
  - the post-hoc gate removed D2C only because it was applied asymmetrically;
  - D2C's headroom is by far the thinnest: 1.8 calls of managed COGS per outcome, against 17-170 for the others.
- **V3 (both):** the same as V1.

**The per-minute gate, applied to everyone** (`scorecard-gate-grid.csv`), depends on which price statistic is used:

| market price statistic | against COGS A (₹5.88) | against COGS B (₹3.23) |
|---|---|---|
| mid of range | all 9 fail | only D2C fails |
| top of range | only D2C fails | all 9 pass |
| low of range | all 9 fail | all 9 fail |

So "D2C fails a price gate" holds only for a chosen cell. It is not a property of a symmetric rule.

**Consequence for SYNTHESIS.**
- Alternate 2, lending reminders, is not supported by the scorecard without the added criterion: it is #8 on V1 and #13 on S1.
- Real estate's tie with insurance holds under every variant.
